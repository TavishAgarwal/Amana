Genuinely new (integration/setting/evaluation, not crypto):
(a) consent-gated two-stage disclosure: PSI-cardinality bit → condition only on mutual signed revocable consent;
(b) consanguinity-aware cascade invites reusing consent tokens;
(c) Arabic/English explainer with teach-back measured on Emirati users + Arabic GC evaluation set — most publishable gap (no Arabic GC LLM eval found).
