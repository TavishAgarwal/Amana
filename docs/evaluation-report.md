# AMANA: Evaluation report

Source: `sim/eval/results.json` (harness `sim/eval/harness.py`, seeds fixed). Re-run on 9 Nov 2026 with the check on the devices (two-way, no tokens in the hello) and the local AI switched on. Every number below is copied from that file; if they ever disagree, the file is right. Gene panel is the real 111-gene ClinVar-based list; relative gene frequencies come from gnomAD v4 (Middle Eastern group) x ClinVar, scaled to the 4.8% target; couples are still simulated.

| Area | Result |
|---|---|
| Correctness | 5,000 couples, every one issued by two different labs: 271 incompatible, **0 missed, 0 false alarms** (100%); both sides computed the same answer on all 5,000 |
| Simulated incompatible rate | 5.42% (271 of 5,000; target 4.8%, within the ±1.5 point tolerance) |
| Privacy/security suite | 26 tests passed (forged token, all-genes attack, replay, expiry, revoke, audit tamper, relay log scan, no tokens in the hello, each side computes its own result, no reveal without the serving side's consent). Browser side: two wallets over the real relay, one request per session, no token in anything relayed (`apps/wallet/tests/check.test.mjs`) |
| Red-team | 100 prompts (Arabic, English, mixed), run with the local model on (`llama3.1:8b` via Ollama, selecting reviewed sentences only): **0 directive, 0 unsupported**, 22 of 22 benign questions answered, 71 s in total. Automated check only; **two human reviewers still needed** |
| On-device answers (wallet) | Questions answered on the phone, never sent. Same 100 red-team prompts: **0 directive, 0 unsupported**, 22/22 benign answered, 3/3 off-topic refused, for both levels. Relevance (expected sentence in the answer): rules, every phone, 13/40; 4.9 MB on-device model 37/40, held-out 19/24 (right card 24/24); e5-small (135 MB, not shipped) 39/40 and 19/24. The held-out set informed one round of rule fixes, so fresh questions are needed before these are final (`apps/wallet/tests/ask-eval.mjs`, `docs/model-card.md`) |
| Routing | 1,000 of 1,000 cases to the expected tier |
| Load: the check itself | 10,000 real two-way checks (two PSI runs each), 0 errors, 46.2 ms per check on one core (462 s in total). In the product this work runs on the two phones, not on a server. This times the Python wallet logic, not the relay, phones or network |
| Load: servers (10 Nov) | `loadtest/run.sh`, results in `loadtest/results.json`, on one 10-core laptop with the load client on the same machine. **National token service**: 2,983 signed token sets/s on 1 worker, 4,592/s on 2, about 4,900–5,000/s on 4–8 (the shared machine limits it from there); p95 20–56 ms; 0 errors; every worker issued the same tokens for the same genes. **Relay**: up to 3,176 couples/s through one relay process (one core), each couple a full count check with real message sizes (about 27 KB), p95 41 ms, 0 errors. For scale: a year of UAE and Saudi couples (about 160,000, `docs/commercial-case.md`) would pass through one relay in under a minute. Not measured: phones on real networks, Azure, and memory per waiting session |
| Cost per couple (AED) | **Estimate** about 0.11–0.28 AED per couple per year at 10,000 couples (hosting only; see `docs/cost-model.md`; prices are assumptions until checked in the Azure calculator) |
| Card coverage | **51.7%** of simulated incompatible couples (15 cards over a 111-gene panel) share a gene that has a reviewed card (2.3% with the original placeholder panel). Indicative only: frequencies are scaled to the target, not measured |
| Real-frequency check | Using the gnomAD Middle Eastern x ClinVar frequencies **without** calibration (35% first-cousin mix), the implied incompatible-couple rate is **3.98%**, against the 4.8% target. It is an under-estimate by construction (see `docs/limitations.md`), so the target is plausible but not confirmed |
| Understanding before/after, fairness | Not run with people yet. The study mode (`/study`) and dashboard are built and tested; protocol and analysis plan in `docs/study-kit.md`. Synthetic dashboard data is labelled and is not a result |
| Time to counselling, reach | Not measured |
